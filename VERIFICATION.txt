Changes:
- Finally-based debugger event resumption, idempotent disconnect, synchronized
  trace snapshots/terminal state, per-camera concurrent-capture guard.
- Start-class request filter before capture, selected-thread requests during
  capture. Full selected-thread call depth preserved across recorded filters.
- Class-prepare-based field watch waiting; initializer writes captured.
- Default 100000-event trace bound, explicit truncation metadata, optional JSONL
  streaming with no-retain mode. Pending field changes bounded at 10000 with a
  dropped-count API and CLI diagnostics.
- Named CLI options, overrides/help/version, timed watchers, strict timeout exit
  3, safe distinct input/output paths and offline report command.
- Self-contained text/HTML flow walkthroughs styled from the supplied prompt:
  context, highlights, call/mock summary, narrative/reference table, method counts
  and inclusive durations, partial-call annotations, encoded IDE links and footer.
  Mock/override provenance comes exclusively from explicit author declarations.
- Retained org.onestonesoup:core:0.1.4 EntityTree model. Local strict JSON codec
  handles commas/quotes/brackets/Unicode/controls/empty arrays and rejects malformed
  input. Existing trace numbers/booleans remain string-valued.
- Compatible plugin signatures retained; failed traces report FAILED; truncated
  traces use COMPLETED with an explicit partial-data message.

resumption, concurrent cancellation/snapshots, idle timeout without debugger
